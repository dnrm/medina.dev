# Coding Academy Monterrey

Una página de inicio para una escuela de ciencias computacionales en Monterrey que presenta su portafolio y sus objetivos. Construida con React.js. Es un proyecto sencillo, pero fue mi primer trabajo pagado, y Coding Academy es donde descubrí mi pasión por el desarrollo web.
